# YouTube 字幕リーダー

YouTube の英語動画の字幕を、段落ごとに読みやすく整えて表示する英語学習アプリです。

## できること

- **URL を貼るだけで字幕を取得**し、文・間（ま）・話者交代をもとに段落へ整形
  - 句読点のない自動生成字幕も、無音区間で区切って文頭の大文字化などを行います
- **単語にカーソルを合わせると意味を表示**（日本語訳・発音記号・英英定義・例文）
  - 活用形（studies, running など）は原形も探します
  - 🔊 で発音を再生、☆ で単語帳に保存（保存した単語は本文中に下線表示）
- **フレーズを選択すると日本語に翻訳**
- 時刻ボタンでその場面から再生、再生中の段落をハイライトして自動スクロール
- **履歴を自動保存**（字幕ごと保存されるので 2 回目以降は即表示）。検索・削除も可能
- 文字サイズ調整、全文コピー、ダークモード、スマホ表示に対応

## 使い方

Node.js 18 以上が必要です（追加パッケージは不要）。

```bash
cd youtube-subtitle-app
node server.js
```

ブラウザで http://localhost:3000 を開き、YouTube の URL を貼り付けてください。

### サーバーなしで使う場合

ブラウザからは YouTube の字幕を直接取得できない（CORS 制限）ため、自動取得には `server.js` が必要です。
サーバーなしで `index.html` を開いた場合や、自動取得に失敗した場合は、
YouTube の「…」→「文字起こしを表示」の内容をコピーして貼り付けると同じように整形できます。

## データの保存先

履歴・単語帳・辞書キャッシュはブラウザの localStorage に保存されます（端末・ブラウザごと）。

## 利用している外部サービス

- 英英辞書: [Free Dictionary API](https://dictionaryapi.dev/)
- 日本語訳: [MyMemory Translation API](https://mymemory.translated.net/)（無料枠は 1 日あたりの上限あり）
- 動画再生: YouTube IFrame Player API
